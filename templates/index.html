Propósito Educativo

FinancialAR OSINT es una herramienta educativa para concientización sobre inteligencia financiera e ingeniería social.

Fuente de Datos

Los datos se obtienen directamente de la API oficial del Banco Central de la República Argentina (BCRA).

Privacidad

Importante: Esta herramienta no almacena ni procesa datos personales. Todas las consultas se realizan directamente a la API del BCRA.

Responsabilidad

Los resultados mostrados son informativos. Para decisiones financieras importantes, consulte con un profesional.
